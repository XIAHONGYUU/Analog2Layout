# 尺寸、m 和匹配组（用户定义版）

> 这一版按用户给定的单位 W 和匹配组重新换算；原始电路没有 `m` 参数。
> 所有 MOS 的 **L 仍按原图 2 µm**（如果 L 也要改，需要另外给 L）。
> `m` 是并联 multiplicity，`total W = W × m`。

实现版本：[`opamp.sized.sp`](opamp.sized.sp)（单位 W + m）。

## 匹配组检查

### M15 / M3 / M4

```text
M15: W=8, m=16, total=128
M3 : W=8, m=8,  total=64
M4 : W=8, m=8,  total=64
```

比例 **16 : 8 : 8 = 2 : 1 : 1**。
三个管子单位 W 都是 8 µm，适合同一 unit cell；M15 用 16 个，M3/M4 各 8 个。

### M16 / M5 / M10

```text
M16: W=2, m=81, total=162
M5 : W=2, m=81, total=162
M10: W=2, m=97, total=194
```

比例 **81 : 81 : 97**，即约 **1 : 1 : 1.1975**。
三个管子单位 W 都是 2 µm，m 是整数；但 M10 仍是 1.2 左右的近似比例，不是精确 1.2：

```text
1.2 × 162 = 194.4
```

如果 1.2 是有意设计，194/162 的误差约 -0.2%；如果要求精确 1.2，需要重新定 M10 的 total W 或 unit W。

### M1 / M2

```text
M1: W=10, m=8, total=80
M2: W=10, m=8, total=80
```

1 : 1。

### M8 / M9

```text
M8: W=9, m=12, total=108
M9: W=9, m=12, total=108
```

1 : 1；原来 109 改成 108 后，108/9=12，m 正好整数。

### M6 / M7

```text
M6: W=12, m=20, total=240
M7: W=12, m=20, total=240
```

1 : 1。

### M11 / M12 / M13

```text
M11: W=8, m=30, total=240
M12: W=8, m=30, total=240
M13: W=8, m=80, total=640
```

比例 **30 : 30 : 80 = 3 : 3 : 8**。
三个管子单位 W 都是 8 µm；M13 是 M11/M12 的 8/3 倍。

## 还有没有其他管子

16 个 MOS 都已经覆盖：

```text
M1  M2  M3  M4  M5  M6  M7  M8
M9  M10 M11 M12 M13 M14 M15 M16
```

没有遗漏的 MOS。

不属于 MOS、但也需要标注的：

| 器件 | 值/尺寸 | 说明 |
| --- | --- | --- |
| C1_CC | 5 pF | MOM，固定 **5 µm × 10 µm = 50 µm²** 方块 |
| CL | 10 pF | 外部负载，**对版图没有影响** |
| I_BIAS | 100 µA | 理想偏置电流源，**对版图没有影响** |
| VDD / VSS | 2 V / 0 V | 电源，**对版图没有影响** |

R1 已经给出：`w=2 µm, L=3 µm, m=4`。

C1_CC 在网表里固定为：

```text
C1_CC vout n012 5p area_core_um2=50 w_layout_um=5u h_layout_um=10u
```

这是 **固定几何覆盖**：直接采用 5 × 10 µm 的 MOM block（50 µm²），
不再用 2 fF/µm² 的 cap density 规则去反算面积。

## 结论

- 原始网表 **没有 m**；这里 m 是按你给的 unit W 自动换算出的 **版图 multiplicity**；
- 所有 MOS 总 W 保持原设计（M8/M9 从 109 改为 108）；
- 匹配组比例：15/3/4 = 2:1:1，16/5/10 = 81:81:97，1/2 = 1:1，8/9 = 1:1，6/7 = 1:1，11/12/13 = 3:3:8；
- 唯一仍需确认的是 **M10 的 194/162 ≈ 1.2 比例**是否有意。
