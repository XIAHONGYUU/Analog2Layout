## What this overlay adds

Compared with the older [`../ldo.annotated.sp`](../ldo.annotated.sp), this overlay
has layout-ready groups and extended roles:

```text
group=  AMP / OUT / BIAS / REF / START / CTRL_EN / CTRL_SEL / FB / PASSIVE
role=   A2L-compatible role
nll_role= extended role, e.g. pass_device / feedback / decap
```

Examples:

```spice
XM59 ... role=output_stage nll_role=output_stage group=OUT
XM61 ... role=output_stage nll_role=pass_device group=OUT
XR4  ... nll_role=feedback group=FB match=FB_DIV
XR5  ... nll_role=feedback group=FB match=FB_DIV
XC1  ... role=decap nll_role=decap group=PASSIVE
```

## Reproduce

Use the same NetlistLabel commit and the raw LDO file:

```bash
cd /path/to/AnalogNetlistLabel
git checkout 8cefac8
python3 -m netlistlabel analyze \
  /path/to/Analog2Layout/examples/sky130_ldo_01v8/ldo.sp \
  --out out/repro/ldo
```

Review packet:

```bash
python3 -m netlistlabel review out/repro/ldo/annotation.json --out review/repro/ldo
```

Evaluate after editing `review.csv`:

```bash
python3 -m netlistlabel evaluate \
  out/repro/ldo/annotation.json review/repro/ldo/review.csv \
  --out out/repro/eval/ldo
```

Exact hashes can differ if the source path or NetlistLabel version changes; the
semantic schema and evaluation protocol are the reproducible contract.
