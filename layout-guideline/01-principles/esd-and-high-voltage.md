# ESD 与高压

## 一句话

ESD 保护是一个从 PAD 到地/电源的完整放电路径；器件存在、DRC 通过，都不等于路径成立。

## 为什么

ESD 电流会走最低阻抗路径，可能经过电源网络、衬底、guard ring、level shift 或邻近模块。高压器件还涉及击穿、间距、well/ring、SAB、contact/via 和 latch-up。只检查单个器件或单条规则，容易漏掉系统级路径。

## 判断问题

1. 放电路径从哪里进、经过哪些器件/电源/地、从哪里出？
2. ESD 电源和内部电路电源是否分开？PAD 附近是否有禁放区？
3. 高压/低压器件的 well、ring、SAB、contact、via 是否符合当前工艺？
4. 跨压域接口在断电/上电/切换状态下是否可控？
5. latch-up 触发条件是否可复现？对照版本差异在哪？
6. shrink 后绝对尺寸是否按最终制造尺寸复核？

## 常见反例

- 只放 ESD 器件，不检查电源/地回路；
- ESD 电源与内部电源共用路径；
- 只按 DRC 通过，不做人工路径复核；
- 跨压域信号直接用电平转换/反相器，断电态悬空；
- 只检查常温，不看高温 FF 漏电；
- 把某项目的 via 数、间距当成所有工艺的固定值。

## 验证与证据

- ESD 路径图与电源域划分；
- 器件/ring/SAB/contact 的版图检查；
- latch-up / ESD 测试或对照实验；
- 高温 FF 漏电；
- 规则版本、工艺 shrink 说明、未覆盖项。

## 适用边界

- 具体 via 数、间距、SAB 尺寸由 PDK/ESD rule 决定；
- 不同电压域、PAD 类型、封装/系统注入路径不同；
- 不是所有跨压域信号都能用同一种 level shift。
