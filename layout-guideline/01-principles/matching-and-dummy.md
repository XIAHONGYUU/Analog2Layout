# 匹配与 dummy

## 一句话

匹配的核心不是“两个管子画得一样”，而是让它们在制造、应力、温度和寄生环境上尽量一致。

## 为什么

光刻、刻蚀、CMP、注入和退火都不是理想过程。器件的边缘、邻居、密度、方向、走线环境不同，实际得到的 Vth、β、电阻、电容就会不同。dummy、common-centroid、interdigitated、guard ring 都是为“环境一致”服务的手段，不是目的本身。

## 判断问题

1. 这个匹配组的误差会进入哪个指标？offset、增益、温漂、INL、时钟占空比？
2. 组内器件的方向、finger 数、周围 dummy、well/ring 环境是否一致？
3. 组内走线的长度、层、宽度、过孔、耦合环境是否一致？
4. 边界器件是否比内部器件少一侧邻居？dummy 是否对称？
5. 加 dummy / 加 ring 后，寄生和面积是否反而破坏了更重要的指标？

## 常见反例

- 只加 dummy，不管 dummy 的尺寸、连接和位置；
- 只追求几何对称，不管走线寄生和回流；
- 匹配组跨越了不同的 well / ring / 电源域；
- 为了面积去掉边界 dummy，却保留“中心布局”的口号；
- 把“加 dummy”当成所有模块的固定动作，不区分匹配、密度、ESD 需求。

## 验证与证据

- 匹配组的定义（哪些器件、什么比例、什么方向）；
- 版图截图/坐标：dummy、ring、走线环境；
- 后仿/蒙特卡洛/offset/INL 等目标指标的前后对比；
- 如果无法量化，至少记录“当前假设”和“未验证项”。

## 适用边界

- 具体 dummy 数量、尺寸、间距、ring 宽度由工艺/项目/规则包决定；
- 不是所有模块都需要 common-centroid；
- dummy 可能增加寄生、漏电和面积，必须和电路目标一起权衡。
