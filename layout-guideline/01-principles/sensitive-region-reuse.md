# 敏感区与可复用区

## 一句话

版图不是“一个总面积”，而是**敏感区 + 非敏感区**：敏感区需要特殊画法、ring、WPE 间距、dummy、屏蔽和走线预留，往往可以复用；非敏感区可以自由发挥。

## 为什么

同一个模块里，不同区域的风险完全不同：

- 输入对、参考、电流镜、trim、采样、ESD/高压、关键电源路径：对匹配、寄生、噪声、可靠性敏感；
- 偏置/数字/非关键走线/普通 decap：相对不敏感，可以灵活布置。

把两者混成一个面积数字，会同时低估敏感区的成本、高估非敏感区的约束。

## 敏感区通常包含什么

- 器件本身（W/L/nf/m）；
- guard ring / 独立围环；
- WPE / STI / well / 扩散间距；
- dummy（边界、密度、匹配）；
- 屏蔽（参考/电源/时钟）；
- 关键走线的预留通道/线宽/过孔；
- 与敏感区相邻的 keepout。

## 判断问题

1. 这个区域里哪些器件/网络是“敏感”的？依据是什么（offset/噪声/参考/ESD/高压/电流）？
2. 敏感区需要哪些强制画法？ring、WPE 间距、dummy、屏蔽、走线预留分别占多少？
3. 这个敏感区能否从以前项目复用？工艺、电压域、温度、频率、模块边界是否可比？
4. 复用会带来什么版本债/验证债？
5. 非敏感区有哪些自由度？电源/地/走线/面积如何填？
6. 总面积里，敏感区/非敏感区/预留通道各占多少？

## 常见反例

- 只算器件面积，不算 ring/WPE/dummy/屏蔽/走线预留；
- 把“核心区”理解成纯器件 OD，忽略强制画法；
- 敏感区为了省面积去掉 ring/dummy；
- 复用旧敏感区，不检查工艺/电压/模块边界；
- 非敏感区照搬敏感区规则，浪费面积；
- 只看 DRC，不看 WPE/寄生/匹配/ESD。

## 验证与证据

- 敏感区清单（器件/网络/原因）；
- ring/WPE/dummy/屏蔽/走线预留的版图检查；
- 复用条件与差异清单；
- 后仿/测试/问题关闭记录。

## 适用边界

- 具体 WPE/ring/dummy/间距数值由 PDK/公司规则决定；
- 不是所有模块都有可复用敏感区；
- 复用不是“复制粘贴”，必须带版本和验证范围。
