# 信号流与寄生

## 一句话

先问“谁驱动、谁接收、从哪里回来”，再决定线宽、屏蔽、对称和层；不要从“这根线看起来重要”开始。

## 为什么

同一根线在不同模块里可能是高速、低噪声、大电流、参考或控制线。它的版图要求取决于：

- 驱动能力和负载；
- 边沿/带宽/建立保持；
- 噪声敏感度和干扰源；
- 回流路径和参考；
- 寄生 R/C 对目标指标的影响。

不先确定信号属性，就会把所有线都当高速线，或者把关键参考线当普通线。

## 判断问题

1. 这个节点的驱动强/弱/无？负载是什么？
2. 电平/摆幅/共模是什么？是否跨电源域？
3. 静态/慢速/快速？边沿和建立保持要求？
4. 它被谁干扰、它干扰谁？回流在哪？
5. 匹配/对称/屏蔽/线宽，分别服务于哪个指标？
6. 后仿要看 C+CC 还是纯 R？关键节点是哪几个？

## 常见反例

- 敏感线只加屏蔽，不看屏蔽参考和新增电容；
- 多通道只做几何对称，不看路径长度/耦合/回流；
- 参考线只看“连上了”，不按允许压降和参考电流反推线宽；
- 长走线不做换层/跳线/缓冲规划；
- 把“全驱线屏蔽”当成万能解，忽略它可能影响其他位置；
- 为过 LVS 随手改线，后续不回到寄生网表。

## 验证与证据

- 关键 net 列表和属性；
- 前仿假设（寄生估算）与后仿提取结果；
- C+CC / 纯 R 网表回查；
- 屏蔽前后、加宽前后、对称前后的目标指标对比；
- 如果只做了形式措施，明确写“未量化”。

## 适用边界

- 具体线宽、屏蔽层、间距由工艺/项目/信号属性决定；
- 不是所有敏感线都要屏蔽；屏蔽可能增加寄生、改变建立时间；
- 形式对称不能保证电气寄生一致。
