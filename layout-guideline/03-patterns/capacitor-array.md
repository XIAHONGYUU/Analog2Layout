# 电容阵列

## 保护什么

比例精度、绝对值、匹配、寄生、噪声、线性度。

## 必须一起处理

- unit cap 的类型（MOM/MIM/MOS）；
- 阵列的串联/并联/抽头；
- dummy/边界/ring；
- 上下极板走线/屏蔽；
- 与地/衬底的寄生；
- 开关/比较器/参考的连接。

## 常见画法

- 同类型、同 unit、同环境的阵列；
- 边界 dummy 或 dummy unit；
- 上下极板走线对称，避免一侧额外寄生；
- 关键 cap 远离噪声/时钟/大电流线；
- MOM 的 M1 使用要谨慎（易受干扰）；
- 抽头位置/走线保持对称。

## 常见错误

- 只匹配电容值，不匹配上下极板寄生；
- 边界 unit 与内部 unit 环境不同；
- 一侧走线多、另一侧少；
- 时钟/数字线跨电容阵列；
- 用 MOS 电容替代 MOM/MIM 而不评估线性度/寄生；
- 忽略电容对衬底的寄生。

## 验证

- 比例/绝对值/线性度/噪声前后仿；
- 关键节点寄生；
- 版图截图：unit、dummy、ring、上下极板；
- 与地/衬底寄生评估。
