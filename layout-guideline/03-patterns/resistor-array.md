# 电阻阵列

## 保护什么

比例精度、温漂、匹配、噪声、寄生、电流密度。

## 必须一起处理

- unit resistor 的尺寸/方向/材料；
- 阵列的串联/并联/抽头；
- dummy/边界/ring；
- 走线层、宽度、过孔、跨线；
- 上方/下方的金属或屏蔽；
- 电流路径与压降。

## 常见画法

- 同方向、同 unit、同环境的阵列；
- 两端 dummy 或边界 unit；
- 抽头位置对称，走线环境一致；
- 关键电阻独立围环；
- 避免在匹配电阻上跨线；必须跨时保持所有 unit 的走线环境一致；
- 大电流电阻按电流密度和压降加宽。

## 常见错误

- 只匹配 W/L，不匹配走线和邻居；
- 一处跨线、其他不跨；
- 抽头/连线改变某些 unit 的寄生；
- 电阻阵列上方走噪声线；
- 用最小线宽走大电流；
- dummy 尺寸/位置不对称。

## 验证

- 比例/绝对值/温漂前后仿；
- 关键节点的寄生 R/C；
- 电流密度/压降；
- 版图截图：unit、dummy、ring、跨线；
- 规则包中的电阻类型/密度/间距。
