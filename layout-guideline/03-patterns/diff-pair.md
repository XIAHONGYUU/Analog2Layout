# 差分对

## 保护什么

offset、噪声、共模抑制、增益、输入寄生。

## 必须一起处理

- 两只输入管的尺寸、方向、finger 数、m 数；
- 源极公共节点/尾电流；
- 栅极走线、输入 PAD/ESD 路径；
- 负载/电流镜的对称；
- well/ring/衬底接触；
- 输入对周围的 dummy 和边界环境。

## 常见画法

- 共质心 / 交叉指状（按匹配目标选择）；
- 输入对跨对称轴；
- 两侧 boundary dummy 对称；
- 栅极走线短、对称、避免跨噪声源；
- 尾电流在输入对下方/附近，公共源路径短；
- guard ring 包围，注意衬底噪声。

## 常见错误

- 只做几何对称，不看走线寄生；
- dummy 只加一侧；
- 输入对靠近时钟/数字/开关线；
- 尾电流路径长、窄、共享；
- 忽略输入 PAD/ESD 的寄生和耦合；
- 为了面积把输入对拆到不同 well/ring。

## 验证

- offset / 噪声 / 共模 / 增益前后仿；
- 输入对与尾电流的寄生 R/C；
- 版图截图：对称轴、dummy、ring、走线；
- 如果无法量化，记录未验证项。
