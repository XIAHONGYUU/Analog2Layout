# Output Stage（输出级）

## 保护什么

输出摆幅、驱动能力、稳定性、电流密度/EM、ESD、过流/短路、回流。

## 必须一起处理

- 输出 PMOS/NMOS 的 W/L、finger、m；
- 电源/输出/地走线的宽度/层/过孔；
- 输出 PAD/ESD 路径；
- 补偿电容/反馈/sense 的取点；
- 大功率电源与 OP 前级电源的分域；
- 输出级周围的 guard ring/隔离。

## 常见画法

- 输出级放边缘，靠近 PAD/输出；
- 电源/输出/地按电流密度加宽，多打孔；
- 大功率电源与 OP 前级电源分开；
- 输出反馈/sense 从输出端单独取；
- 补偿电容靠近输出级，远离噪声；
- ESD 器件靠近 PAD，路径完整；
- 输出管匹配/环境一致（如同属一个输出组）。

## 常见错误

- 最小线宽走输出电流；
- 单点/细线连接大负载；
- 大功率电源与 OP 前级共用；
- sense 线共享大电流路径；
- 补偿电容离输出太远；
- 只过 DRC，不检查 ESD/latch-up/EM；
- 输出管拆到不同环境。

## 验证

- 负载瞬态/稳定性/相位裕度；
- 输出摆幅/驱动；
- IR/EM；
- ESD/latch-up；
- 输出噪声/PSRR；
- 版图截图：输出级、电源/地、ESD、sense。
