# 电流镜

## 保护什么

镜像比例、Vth 匹配、输出阻抗、噪声、电源抑制。

## 必须一起处理

- unit cell 的尺寸/方向/finger；
- diode 与 mirror 的源极/well/ring 环境；
- 比例器件的 m 数和连线；
- 边界 dummy / dummy branch；
- 电源/地路径与压降；
- 镜像输出节点的寄生。

## 常见画法

- 同方向、同 finger、同环境的 unit cell；
- diode 与 mirror 相邻或同质心；
- 比例用 m 数/并联，不随意改 W/L；
- 边界加 dummy 或 dummy branch；
- 源极到电源/地的路径短、对称；
- 镜像输出走线避免跨噪声源。

## 常见错误

- diode 和 mirror 环境不同；
- 只改 W/L 做比例，破坏 unit cell 一致性；
- 边界器件少一侧邻居；
- 电源线细/单点，导致镜像电流随位置变化；
- 镜像输出长距离跨线，寄生不一致；
- 忽略 dummy branch 的漏电/面积。

## 验证

- 镜像电流/比例的前后仿；
- 失配/蒙特卡洛；
- 电源/地压降；
- 版图环境检查；
- 比例与 m 数的可追溯记录。
